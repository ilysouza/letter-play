# Assets visuais

- `words/`: imagens ligadas a palavras e atividades pedagógicas. Use nomes em minúsculas, como `caderno.jpg`.
- `brand/`: identidade visual geral do Letter Play, como fundo e materiais de marca.

Para trocar uma imagem de palavra, mantenha o nome do import em `client/src/content/wordBank.ts` ou atualize esse import junto com o novo arquivo. Prefira JPG otimizado para fotos e PNG apenas quando precisar de transparência.
